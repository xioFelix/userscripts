# 闲鱼网页版暗夜模式

为闲鱼网页版提供护眼暗夜主题，覆盖首页、搜索、商品详情、个人中心、订单、发布页面及闲鱼 H5 规则页面。

## 安装

1. 安装 [Tampermonkey](https://www.tampermonkey.net/)。
2. 点击[安装闲鱼网页版暗夜模式](https://raw.githubusercontent.com/xioFelix/userscripts/main/tampermonkey/goofish-dark-mode/goofish-dark-mode.user.js)。
3. 在 Tampermonkey 安装页面确认安装。

## 使用

- 默认启用暗夜模式。
- 在 Tampermonkey 菜单中选择“切换闲鱼暗夜模式”可随时开关。
- 快捷键：`Alt/Option + D`。
- 设置会自动保存。

## 自动更新

脚本包含固定的 `@updateURL` 和 `@downloadURL`。发布新版本时递增 `@version`，Tampermonkey 会按照用户设置的检查间隔自动更新。
