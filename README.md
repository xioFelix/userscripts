# Userscripts

Felix 的浏览器用户脚本集合。

## Tampermonkey scripts

| 脚本 | 说明 | 安装 |
| --- | --- | --- |
| [闲鱼网页版暗夜模式](tampermonkey/goofish-dark-mode/) | 为闲鱼网页版提供暗色背景和高可读性文字 | [安装脚本](https://raw.githubusercontent.com/xioFelix/userscripts/main/tampermonkey/goofish-dark-mode/goofish-dark-mode.user.js) |

脚本安装后由 Tampermonkey 根据 `@version`、`@updateURL` 和 `@downloadURL` 自动检查更新。
